# Path A — Manual, universal, works today

No code. Covers Reels, YouTube, every app.

## One-time

1. Mac: System Settings → General → AirDrop & Continuity → AirPlay Receiver ON, Allow for Current User.
2. Plug wired buds into Mac, set as output.
3. Same Apple ID + same Wi-Fi on both.

## Each switch

- iPhone Control Center → Screen Mirroring → select Mac.
- Stop: Screen Mirroring → Stop Mirroring.

## Costs

- One tap each way.
- Mirrored window appears on Mac.
- Slightly higher latency/battery (video mirrored too).
- DRM apps (Netflix etc.) may black out video; audio usually still plays.
